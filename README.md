## How to open

Open any `.html` file in a modern browser. No build step required; Bootstrap and fonts are loaded from CDN.

## Requirements met

- No JavaScript
- No `novalidate` attribute
- Task 1 matches the design at 375 px and 1280 px
- Task 2 validation uses only `type`, `required`, `min`, `max`, `step`, `minlength`, `maxlength`
- Task 3 has ≥10 documented problems + fixed form that works with keyboard only
